# Fluxo - Aplicativo de Finanças Pessoais

Este projeto é uma aplicação mobile desenvolvida com **Ionic** e **Angular**, focada em oferecer uma solução intuitiva e eficiente para o controle financeiro pessoal.

## 📌 Status do Projeto
Esta versão atual é um **protótipo de teste** que valida a estrutura de navegação e a integração nativa.
*   **Página Atual:** Sobre Nós (Institucional).
*   **Build:** APK gerado com sucesso via Capacitor e Android Studio.

## 🚀 Sobre o Aplicativo
O **Fluxo** foi idealizado para ajudar usuários a:
*   Acompanhar despesas diárias de forma simples.
*   Planejar orçamentos mensais.
*   Visualizar a saúde financeira através de uma interface moderna e amigável.

## 🔌 Integrações (APIs)
Para fornecer dados precisos e em tempo real, o aplicativo utiliza as seguintes APIs:
*   **[brapi.dev](https://brapi.dev/)**: Utilizada para consultas de ações, fundos imobiliários e dados do mercado financeiro brasileiro.
*   **[awesomeAPI](https://docs.awesomeapi.com.br/)**: Utilizada para conversão de moedas, cotações de câmbio e criptomoedas.
